The TH/EN sections for program 04 and the image resource section of Figma file `c7zk0NV5ZHPNlLf5EgDHAb` were reviewed in a browser. One tutorial PNG downloaded for checking before the ZIP request remains separately.

## Scope

- Idle: Thai and English standby screens and the language selection guide. Holding for 2 seconds switches Thai ↔ English while staying on Title, and a short press and release starts in the current language. Returning to Idle keeps the language of the last experience; the app starts in Thai. The selected language persists through Tutorial → Game → Result → Statistics → Finish.
- Tutorial: both languages share the six pictures from the English design. The first picture is also used in the existing lift/move/landing/repeat-twice animation. The original card frames and shadows, the board and decorations are kept.
- Game: per-language headers, category names and button guides. The guide shows according to the actual completion state of the six slots.
- Result: per-language scores 0 to 6, category names and button guides. Photos freeze at submission, and the actual answers decide the stamps. The result board scale is set to 1 as in the original design.
- Statistics: per-language title, human label and progress guide. Ratios and graphs are calculated from the stored actual response counts.
- Finish: per-language card removal guide and 5-second home guide. The video decoder, final frame hold and automatic return after clearing all seven physical readers are kept.
- Game, result and statistics buttons advance on a short press and release. Holding for 5 seconds returns home without submitting. The directly called `PressButton1()` API remains the completed-short-press entry point. External adapters that provide down/up use `ClassificationButtonGesture.SetPhysicalButtonPressed(bool)`.

## Implementation

- `Assets/UI/Figma20261104`: per-language UI and shared tutorial cards. Existing background and board sources were combined with exported static areas, and dynamic scores, ratios and photos are not baked into backgrounds.
- `ClassificationUiLanguage`: swaps through Image/Sprite references serialized in the scenes. Builds do not use AssetDatabase or temporary URLs.
- `ClassificationButtonGesture`: distinguishes a short press from the 5-second home action.
- `RfidCardImageCatalog`: holds the card mapping above in one place.

The actual wiring is the `ClassificationUiLanguage` serialized references in the three scenes.
