# RFID 입력과 Finish 복귀 — 2026-10-28

GamePanel 진입 전의 RFID 입력은 게임에 반영하지 않는다. `RfidInput`은 실제 일곱 리더의 상태를 계속 보존하며, 테스터·블록 제거 안내·Finish 복귀 조건은 이 물리 상태를 사용한다.

`RfidImagePanel.OnEnable`이 `ContentGate.BeginGameInput`으로 빈 게임 입력 세션을 시작한다. 진입 시 이미 놓인 블록은 복사하지 않는다. 같은 블록의 반복 감지로는 새 배치 이벤트가 생기지 않으므로, 제거 후 다시 올려야 인정된다. 다른 칸으로 이동하거나 다른 블록으로 교체하는 기존 제거/배치 규칙도 유지된다. 비활성화 시 해당 패널이 소유한 세션만 종료하고 인정 상태를 비운다.

이미지·중앙 미리보기·6칸 완료 안내·점수 제출은 모두 `ContentGate.GetGameCard`를 사용한다. 따라서 이전 블록이 화면에서는 숨겨져도 점수에 포함되는 우회가 없다. 팝업 차단 중에도 제거는 인정 상태에서 삭제하며, 차단 중의 배치는 인정하지 않는다.

Finish의 영상과 RemoveCardPopup 등장 연출이 끝난 후, 실제 리더 일곱 개가 모두 비면 공통 암전 전환으로 Idle 씬에 복귀한다. 중앙 칸과 미등록 블록도 제거해야 한다. 영상 재생 중에 모두 제거해도 영상은 끝까지 재생하며, 이미 비어 있다면 팝업 등장 완료 후 복귀한다.

검증용 실행 코드는 `Temp/RfidFlow/Verify.cs`에 있다. 실제 하드웨어 대신 `RfidInput`의 공통 입력 경로를 사용하며, 정상 점수 제출은 별도 임시 통계 파일에 기록한다.

Unity 2022.3.62f3 Play Mode에서 85개 조건을 통과했다. 실제 Title → Tutorial → Game → Result → Statistics → Finish → Idle 흐름, 진입 전 7개 리더 입력 무시, 같은 블록 반복 감지 무시, 개별 제거·재태그, 이동·중앙 미리보기, 팝업 차단 중 제거·배치, GamePanel 재진입, 정답 제출을 확인했다. Finish에서는 일부 제거 시 대기, 미등록 중앙 블록을 마지막으로 제거한 뒤 복귀, 영상 재생 중 빈 보드로 조기 복귀하지 않음, 재진입 시 이미 빈 보드도 영상·팝업 종료 후 복귀, 이전 씬 언로드를 확인했다. 최종 결과는 `Temp/RfidFlow/result.txt`, 검사 목록은 `Temp/RfidFlow/checks.txt`에 있다. 컴파일 및 기능 오류는 없었으며, 원본 영상의 기존 WindowsMediaFoundation 색 원색 경고가 발생했다. 실물 RFID와 Player 빌드는 검증하지 않았다.
